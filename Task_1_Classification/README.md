# Wine Classification Using Machine Learning

## Project Overview

This project implements supervised machine learning classification using the Wine dataset from Scikit-learn. The goal is to train and compare Logistic Regression and Decision Tree classifiers to predict wine classes based on their chemical properties.

## Dataset

- **Dataset:** Wine Dataset
- **Source:** Scikit-learn
- **Features:** 13 numerical features
- **Target:** 3 wine classes

## Technologies Used

- Python
- Scikit-learn
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow

1. Load and explore the Wine dataset.
2. Split the data into 80% training and 20% testing sets.
3. Apply feature scaling using StandardScaler.
4. Train Logistic Regression and Decision Tree classifiers.
5. Evaluate both models using:
   - Accuracy
   - Precision
   - Recall
   - F1-score
6. Generate classification reports and confusion matrix heatmaps.
7. Visualize decision boundaries using two selected features.

## Model Evaluation

Both classifiers are evaluated on the test dataset. Their performance is compared using accuracy, weighted precision, weighted recall, and weighted F1-score.

**Results:** Add your actual evaluation scores here after running the code.

## Visualizations

The project includes confusion matrix heatmaps to show correct and incorrect predictions. Decision boundary plots illustrate how the models separate classes using two selected features.

## Conclusion

This project demonstrates a basic supervised classification workflow, including data preprocessing, model training, performance evaluation, and visualization.
